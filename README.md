# Team Standup & Retro Board Starter Code

A Kanban-style team standup updates and retrospective board built with React.

## Features
- **Dual Board Modes**: Toggle seamlessly between Daily Standup mode (Yesterday / Today / Blockers) and Retro mode (Start / Stop / Continue).
- **Member Assignment**: Assign updates to specific team members with avatar badges.
- **Card Filtering**: Filter board cards by individual team member.
- **Interactive Card Management**: Add cards to columns, delete cards, and auto-persist to localStorage.
